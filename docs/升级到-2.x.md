# 从 FQGate 0.x / 1.x 升级到 2.x

FQGate 2.x 同时调整了主程序安装结构、AI 插件接入方式和标准数据接口。升级时需要更新主程序，并在新主程序中重新检查 AI 接入；只替换旧版可执行文件或只更新 Agent 插件，都不算完成升级。
> 2.x 兼容 1.x 的接口，具体请参阅本机api文档
## 升级前

1. 退出旧版 FQGate，并关闭正在使用 FQGate 的 AI 会话。旧版和 2.x 默认使用同一个本机端口，不能同时运行。
2. 记下当前使用的数据来源、AI 软件和必要的登录状态。2.x 不会通过复制密码文件或会话文件来完成升级；需要重新登录时，应在 2.x 的“行情数据”页面操作。
3. 不要先手工删除 Codex、Claude Code 等软件中的旧 FQGate 插件或插件市场。2.x 能识别受支持的历史身份，并在实际修改前显示处理计划；提前删除会失去自动识别和恢复所需的上下文。

## 安装 FQGate 2.x

从 [FQGate Agent Releases](https://github.com/fqgate/FQGate-agent/releases) 下载正式版本，不要使用 GitHub 自动生成的 Source code 压缩包。下载页面中的同名 `.sha256` 文件可用于核对文件完整性。

0.x / 1.x 使用旧版更新通道，不应依赖旧主程序的“更新”页面跨越到 2.x；升级到 2.x 时需要按下面的方式手动下载安装。

### Windows

下载文件名包含 `windows-x64.zip` 的压缩包，完整解压到固定文件夹，然后运行其中的 `FQGate.exe`。

- 不要直接在压缩包内运行。
- 不要只把新的 `FQGate.exe` 复制到旧版目录。2.x 的完整目录还包含 `fqgate-updater.exe` 等更新所需文件。
- 正式下载页不提供脱离完整应用目录的单独 EXE；Windows 用户只应下载完整 ZIP 包。

### macOS

在苹果菜单的“关于本机”中确认芯片类型：

- Apple 芯片选择 `macos-arm64.zip`；
- Intel 芯片选择 `macos-x86_64.zip`。

解压后退出旧版 FQGate，将新的 `FQGate.app` 移到“应用程序”并替换旧应用。不要只复制 App 包中的可执行文件。

## 重新确认数据连接

首次打开 2.x 后进入“行情数据”，确认至少一个数据连接可用。

- 普通行情可以使用游客连接，但数据可能延迟或受限。
- 问财、Level-2 等功能仍取决于账号已有权限；升级不会增加账号权限。
- 如果页面提示可以恢复已保存的登录状态，可按页面操作；如果没有可恢复状态，请重新登录。
- 不要在新旧安装目录或用户数据目录之间手工复制登录凭据、Cookie 或缓存文件。

2.x 支持多个数据连接。使用某个账号或特定数据来源前，应在页面中确认当前选择，不能仅凭旧版的登录状态判断。

## 更新 AI 接入

进入 FQGate 2.x 的“AI 接入”页面，选择正在使用的 AI 软件并重新检测。

对于 Codex 和 Claude Code，FQGate 会识别来源明确的历史 FQGate 插件及市场，包括旧名称 `tonghuasun-codex`、`tonghuasun-agent` 和当前名称 `fqgate-agent`。确认迁移计划后，主程序会按顺序处理旧插件、旧市场和当前插件，并在失败时尝试恢复修改前的配置。

无法证明属于 FQGate 的同名市场或插件不会被自动修改。其他 AI 软件的安装条件和自动处理范围不同，应以“AI 接入”页面显示的计划和提示为准。

接入完成后关闭旧 AI 会话并新建会话。已有会话通常不会自动重新载入插件、Skill 或 MCP 工具。

## 升级后的主要变化

| 项目 | 0.x / 1.x | 2.x |
| --- | --- | --- |
| Windows 安装 | 主要使用单个 EXE | 使用包含主程序和 updater 的完整 ZIP 应用目录 |
| AI 插件 | 多套客户端目录、旧插件名或安装包 | 仓库根级 `fqgate-agent` 插件，由主程序按 AI 客户端能力接入 |
| MCP 数据接口 | 主要使用同花顺来源的 `/v1/market/**` | Agent 和 MCP Apps 使用跨数据源的 V2 标准接口 |
| 数据连接 | 主要围绕单一同花顺连接 | 可以管理多个来源实例，调用时可能需要明确选择连接 |
| 交易能力 | 部分历史版本曾包含账户或交易相关工具 | 不提供个人资产、持仓、下单、撤单或资金操作 |

自选股管理只修改关注列表，不是证券交易。

## 验证升级结果

完成以下检查后，才应清理旧安装：

1. FQGate 显示的版本为 2.x，且“行情数据”中的目标连接可用。
2. 在“AI 接入”中重新检测，目标 AI 软件显示已接入。
3. 新建 AI 会话，查询一只明确名称或代码的股票，能够返回带数据时间的当前行情。
4. 如果 AI 软件支持 MCP Apps，图表或信息页面可以正常打开；不支持 MCP Apps 的软件只返回数据并不表示升级失败。
5. AI 工具列表中没有同时出现旧版和当前版两套 FQGate 工具。

确认以上项目后，可以删除旧版程序目录、旧应用和失效快捷方式。不要删除 Windows 的 `%LOCALAPPDATA%\FQGate` 或 macOS 的 `~/Library/Application Support/FQGate`；这些位置也由 2.x 保存当前用户数据。

## 已有程序使用旧接口

仍调用 `/v1/market/**` 的同花顺直连程序可以继续使用旧接口。V2 使用不同的市场标识、字段名称、请求参数和响应结构，不能只把路径中的 `/v1` 改成 `/v2`。

需要迁移自建程序时，先启动 FQGate 2.x，再访问本机的 [2.x 接口文档](http://127.0.0.1:17281/docs)和 [1.0.x 兼容文档](http://127.0.0.1:17281/docs/1.0.x)。旧版 JavaScript MCP 代理不再是 2.x 的接入方式；支持 Streamable HTTP 的客户端应连接 `http://127.0.0.1:17281/mcp`，只支持标准输入输出的客户端使用主程序提供的 `--mcp-stdio` 桥接。

## 常见问题

### 2.x 提示端口被占用

确认旧版 FQGate 已完全退出，再重新打开 2.x。不要通过修改成另一个端口来同时保留两套正式服务。

### AI 中仍显示旧工具

回到“AI 接入”重新检测并完成提示的处理，然后关闭旧会话并新建会话。不要直接删除整个 AI 软件配置目录。

### 升级后没有自动登录

先在“行情数据”中查看是否提供恢复入口；没有可恢复状态时重新登录。不要从旧目录手工复制凭据文件。

### 原来的交易工具不见了

这是 2.x 的产品边界，不是安装失败。FQGate Agent 只提供行情、K 线、资讯、选股、盘口分析和受支持的自选股管理，不提供证券和资金交易操作。
