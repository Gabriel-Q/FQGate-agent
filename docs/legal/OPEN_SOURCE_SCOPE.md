# 开源范围

## AGPL-3.0-only 范围

- 根级插件、Marketplace 与 MCP 清单；
- `skills/**`；
- `mcp-apps/**`；
- `scripts/**`、`tests/**` 与 GitHub Actions 工作流；
- `compatibility.json`、品牌资源和本仓库文档。

以上源码的修改版和衍生版在传播或通过网络向用户提供服务时，应按 AGPL-3.0 提供对应源码，并保留 `ADDITIONAL_TERMS.md` 指定的合理署名。

## 不在本许可证范围

- FQGate 主程序源码、调试符号、研究材料、签名私钥和本机数据；
- 通过 FQGate-releases 单独分发的主程序安装包；
- 第三方组件及其各自许可证文本。

FQGate 编译包适用其随包许可；版本、下载地址和校验值由 [FQGate-releases](https://github.com/fqgate/FQGate-releases) 提供。本仓库只记录兼容关系，并维护插件、Skill 与 MCP Apps 源码。
