# 使用条款

FQGate Agent 是独立开发的非官方本机工具，与同花顺及其关联公司、证券公司和交易所不存在授权、合作或背书关系。

FQGate Agent 用于行情查询、证券研究，以及所用数据源支持的自选股查询和列表管理。行情登录与账号权限在 FQGate 主程序中处理；自选股调整不等于证券买卖。插件不提供个人资产、持仓查询、下单、撤单、申购、转账或其他真实资金操作。插件不会增加账号已有的数据权限，也不得用于绕过登录、付费权限或数据访问限制。

行情、资讯和 Level-2 数据可能延迟、缺失或受账号权限限制。AI 生成内容可能错误或遗漏；本项目不提供投资建议、收益预测或适当性判断，任何投资决定由用户独立作出并承担风险。

不得把低等级数据冒充 Level-2，不得把相关性表述为已证实的因果，也不得把盘口行为直接归因于特定主体。数据事实、AI 计算与推断应明确区分。

本项目不会把行情查询结果上传给维护者。FQGate、数据提供方、发行网站和用户选择的 AI 服务均为独立服务，适用各自条款与隐私政策。
